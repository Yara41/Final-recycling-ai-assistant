# Approved prototypes (2026-11-03)

Reference sources for `docs/superpowers/specs/2026-11-03-campus-redesign-design.md`.

- `directions.html`: the three directions board (A daylight campus, B night gallery, C day to night).
- `home.html`: the approved 5-screen homepage.
- `agent-and-game.html`: the agent page and the 3D sorting game. `/*ENGINE*/` is replaced by `engine.js`.

Images are inlined at build time from `public/` (placeholders `/*IMGS*/`, `/*BOTTLE*/`, `/*ITEMS*/`), so these
files are not meant to be opened directly. The published versions are linked from the spec.
